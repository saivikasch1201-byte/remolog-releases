# Remolog Host — downloads

**Remolog** is free, consent-first remote support. The person who needs help
installs **Remolog Host**; the helper just opens **https://remolog.onrender.com**
in a browser.

## ⬇ Download (Windows 10/11)

**[Download Remolog-Host-Setup.exe](https://github.com/saivikasch1201-byte/remolog-releases/releases/latest/download/Remolog-Host-Setup.exe)**

All versions and release notes: [Releases](https://github.com/saivikasch1201-byte/remolog-releases/releases)

## Installing

1. Run `Remolog-Host-Setup.exe`.
2. Windows may show **"Windows protected your PC"** because the installer isn't
   code-signed yet. Click **More info → Run anyway**.
3. Follow the installer, then open **Remolog Host** from the Start menu.

## Using it

1. Click **Go online**. You'll see a 6-digit **code** and an 8-character **PIN**.
2. Tell your helper the code and PIN (ideally the PIN by phone).
3. Your helper enters them at https://remolog.onrender.com.
4. You choose **Allow view only** or **Allow viewing & control** — nothing is
   shared until you do.
5. A red banner stays on your screen the whole session. Click **Stop sharing**
   any time to end it.

Your screen, chat and files travel directly between the two computers, not
through Remolog's server. Only allow sessions you started yourself — never give
your code and PIN to someone who contacted you unexpectedly.
